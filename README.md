# Ember Lane

Godot 4 night-street adventure: lead **Mira** and her brother **Kabir** through the dark. Rats rule the shadows; only flame holds them back.

**Play:** https://abhi1kush.github.io/ember-lane/

Open the Godot project from the private Origin repo (or ask for a full source mirror). This GitHub repo hosts the Web export for GitHub Pages (`docs/`).

## Controls

| Action | Keys |
| --- | --- |
| Walk | A D / ← → |
| Take, pull, climb | E / ↑ / W |
| Throw ember | F / Space |
| Pause | P / Esc |
| Mute | M |

Touch buttons appear on phones and narrow windows.
